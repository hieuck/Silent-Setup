# Silent Setup v1.0 - Quick Start

## 📦 Package Contents

- **SilentSetup.exe** (155 MB) - Main executable
- **apps/** - 7 pre-configured applications
- **patches/** - Patch templates
- **docs/** - Full documentation
- **config.json** - Configuration file
- **README.md** - Complete user guide

## 🚀 Quick Start (3 steps)

### 1. Extract
Extract `SilentSetup-v1.0-win64.zip` to any folder

### 2. Run
Double-click `SilentSetup.exe`

### 3. Install
- Check the apps you want
- Click "Cài đặt đã chọn" (Install Selected)
- Wait for completion

## ➕ Add More Apps

Click the **"+ Thêm App"** button and fill in:
- App name
- Download link (HTTPS only)
- Silent install parameters
- Detection method (Registry or File path)

## 🔍 Features

- **Search & Filter** - Find apps by name or category
- **Right-click menu** - Edit, delete, view details
- **Context menu** - Edit/delete apps, open homepage
- **Progress tracking** - Real-time installation status

## ⚙️ System Requirements

- Windows 10/11 (64-bit)
- .NET 8 Runtime (app will prompt to install if missing)
- Administrator rights (for most installations)
- Internet connection (for downloads)

## 🛠️ Troubleshooting

**App won't install?**
- Right-click SilentSetup.exe → Run as administrator
- Check antivirus isn't blocking
- View logs for details

**Can't find installed apps?**
- Click "Refresh" button
- Check if app installed to non-standard location

**Download fails?**
- Check internet connection
- Verify download link is still valid
- Check firewall/proxy settings
